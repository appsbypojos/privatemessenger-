# Nexo

Nexo — простой Android-мессенджер с авторизацией через Supabase, поиском пользователей по уникальному нику и личными чатами.

## Что есть

- регистрация и вход по уникальному нику + пароль;
- поиск пользователей по нику;
- личные чаты и отправка сообщений;
- нижняя навигация: Поиск / Чаты / Настройки / Профиль;
- адаптация интерфейса под системные панели Android;
- сборка debug APK через GitHub Actions.

## Сборка APK

GitHub Actions запускает:

```bash
gradle :app:assembleDebug --no-daemon --stacktrace
```

Готовый APK публикуется как artifact `private-messenger-debug-apk`.

## Переменные Supabase

Для GitHub Actions используются secrets:

- `SUPABASE_URL`
- `SUPABASE_KEY`

Не добавляйте реальные ключи Supabase в исходный код или README.

# 🥟 Рецепт вкусных домашних пельменей

## Ингредиенты

### Для теста

- 500 г пшеничной муки
- 1 яйцо
- 200–220 мл воды
- 1/2 ч. л. соли
- 1 ст. л. растительного масла — по желанию

### Для начинки

- 300 г свинины
- 300 г говядины
- 1 крупная луковица
- 70–100 мл холодной воды
- 1 ч. л. соли
- 1/2 ч. л. чёрного перца

## Приготовление

1. Просейте муку, добавьте соль, яйцо и постепенно влейте воду.
2. Замесите упругое тесто. Накройте его и оставьте на 20–30 минут.
3. Для начинки пропустите мясо и лук через мясорубку.
4. Добавьте соль, перец и холодную воду. Хорошо перемешайте — начинка получится сочнее.
5. Раскатайте тесто тонко и вырежьте кружочки стаканом.
6. В центр каждого кружочка положите примерно чайную ложку начинки.
7. Сложите кружок пополам, защипните края и соедините уголки.
8. Варите пельмени в кипящей подсоленной воде. После всплытия варите ещё 3–5 минут.
9. Подавайте со сметаной, сливочным маслом или уксусом с перцем.

## Маленький секрет

Для особенно сочной начинки используйте очень холодную воду и не жалейте лука. А готовые пельмени лучше опускать в воду небольшими партиями, чтобы кипение не прекращалось.
